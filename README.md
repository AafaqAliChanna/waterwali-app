# WaterWali App

WaterWali is the mobile frontend for the WaterWali project, designed to provide a seamless user experience for managing water services.

## Features
- **Secure Authentication**: Integrated with JWT-based login for user security.
- **State Management**: Uses `provider` for clean and efficient state handling.
- **Secure Storage**: Sensitive data is protected using `flutter_secure_storage`.
- **API Integration**: Connects to the WaterWali backend for real-time data handling.

## Getting Started
1. **Clone the repo**: `git clone https://github.com/YOUR_USERNAME/waterwali-app.git`
2. **Install Dependencies**: Run `flutter pub get`
3. **Run the App**: Launch an Android emulator or connect a device and run `flutter run`

## Built With
- [Flutter](https://flutter.dev/) - UI Framework
- [Provider](https://pub.dev/packages/provider) - State Management
- [HTTP](https://pub.dev/packages/http) - API requests
- [Flutter Secure Storage](https://pub.dev/packages/flutter_secure_storage) - Data security
